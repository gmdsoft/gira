# Jira UI 분석 (MD-NEXT 기준)

`rea capture-browser-scenario`로 사용자 Chrome(CDP, SSH 역터널 127.0.0.1:9222)에 연결해 수집했다.
원본 캡처(스크린샷·접근성 트리)는 `analysis/raw/scenarios/jira-*.{png,ax.txt}`에 있고 git에서는 제외한다.
이 문서는 새 서비스의 **기능·디자인 명세 참고 자료**다. Atlassian의 코드나 자산은 가져오지 않는다.

캡처 화면: 목록(`/jira/software/c/projects/NEXT/list`), 칸반 보드(boards/11), 스크럼 보드(boards/12),
백로그(boards/12/backlog), 이슈 상세(NEXT-1860 스토리), 에픽 상세(NEXT-10136).
주의: `/jira/software/c/...`(classic) URL은 `/jira/software/...`로 리다이렉트된다. 캡처·링크는 최종 URL 기준.

  — 같은 보드 안에서 뷰를 전환하는 구조. 우리 PoC의 목록/보드/백로그 탭과 대응된다

- **그룹화** 버튼: 상태·담당자·에픽 등 기준으로 행을 섹션으로 묶는다 (계층 표시의 한 형태)

- **스윔레인**: 그룹 기준 값마다 가로 밴드 (캡처: `Highest 127` — 접기 토글 + 건수)
- **컬럼**: 할 일 12 · 진행 중 0 · 검토 0 · 완료 115 — 머리글에 이름+건수, 연회색 배경 트랙
- **카드**: 좌측 세로 색 막대(에픽 색) + 요약(여러 줄) + 라벨 칩(글로벌설정, 오류보고메일 등) + 타입 아이콘·키 줄 + 하단 메타 줄(경과시간 칩 `75개월`(빨간 시계, 오래됨 경고), 우선순위 아이콘, 아바타 또는 완료 체크)
- 완료 컬럼 카드의 키에는 취소선

## 백로그 (스크럼)

- 툴바: 백로그 검색, 아바타 줄(+10), **버전 / Epic / 유형 / 레이블 / 더 보기** 드롭다운 필터
- **스프린트 섹션** (카드형 블록):
  - 헤더: 체크박스, 접기 토글, **스프린트 이름(굵게)** + 날짜 범위(`5 10월~23 10월`) + `(5개의 업무 항목)` + **상태 요약 칩 3개**(회색=할일 / 파랑=진행 / 초록=완료 건수) + **스프린트 시작** 버튼 + …
  - 설명(목표)이 있으면 이름 아래 회색 작은 글씨
  - 참여자 아바타 줄
  - 하단 `+ 만들기`
- 섹션 사이 드래그 핸들(⇕), 우측에 `N개의 업무 항목`
- **이슈 행**: 좌측 **에픽 색 세로 막대** | 타입 아이콘 | 키(링크) | 요약(말줄임) | **수정 버전 칩**(`NEXT.2.3.1`, `대기버전`) | 상태 드롭다운(색 롯지) | 우선순위 아이콘 | 담당자 아바타
- 활성 스프린트가 없으면 스크럼 보드(활성 스프린트 탭)는 빈 상태 화면: "백로그에서 시작하기" + **백로그로 이동 / 열 구성** 버튼

## 이슈 상세

- **브레드크럼**: `스페이스 / [프로젝트 아이콘] MD-NEXT / [상위 항목 슬롯] / [타입 아이콘] NEXT-1860`
  — **상위 항목이 없으면 "상위 항목 추가" 버튼이 브레드크럼 자리에 노출**, 있으면 부모 키 링크가 그 자리에 들어간다
- 제목(h1) 아래 `+`(하위 만들기·첨부 등) / `…` 버튼
- **주요 세부 정보** 섹션: 커스텀 필드 탭(기본 입력 / 추가 정보 / QA / HubSpot) + 레이블-값 2열 그리드
  - 값이 비면 "컴포넌트 추가", "상위 항목 추가", "레이블 추가" 같은 **추가 유도 텍스트(파란 링크 톤)**
  - 필드: 컴포넌트(칩), 우선 순위(아이콘+이름), **상위 항목**, 수정 버전(칩 `버전없음`), 레이블, 차수, 담당자(아바타 + "나에게 할당" 보조 링크), Sprint, 설명(인라인 편집), 테스트 방법(커스텀)
- **첨부 파일** 섹션(접기 토글, 썸네일 그리드)
- **우측 사이드 패널**: 최상단 **상태 드롭다운(카테고리 색 롯지, 예: `배포` 초록)** + 에이전트 + ✓완료 표시
  - **세부 사항** 카드(Story point estimate, Epic Name(에픽일 때), 보고자) / 개발 / 더 많은 필드 / 자동화 / Svn Commit Log(커스텀) — 각각 접기 카드
  - 하단: `만듦 7년 전 · 업데이트 6년 전 · 해결됨 7년 전` + 구성(⚙)
- 우상단: 잠금(제한), 보는 사람 수(👁 1), 공유, …

## 부모-자식(계층) 표시 명세 — 핵심

Jira는 계층을 **에픽 → 스토리/작업/버그 → 하위 작업** 3단계로 다루고, 화면마다 이렇게 보여준다:

1. **이슈 상세의 "하위 작업" 패널** (스토리/작업에 하위 작업이 있을 때)
   - 섹션 헤더: 접기 토글 + "하위 작업" + 업무 항목 작업 / **열 구성** / **하위 작업 만들기** 버튼
   - **진행률 바 + "N % 완료"** (완료 하위 작업 비율)
   - **정렬 가능한 미니 표**: 업무(타입 아이콘 + 키 링크 + 요약 링크) | 우선 순위 | Story Points | 담당자 | 상태 — 셀마다 **인라인 편집 버튼**(요약 편집, 담당자 편집, 상태 변경)
   - 해결된 하위 작업의 키는 취소선 (접근성 라벨도 "NEXT-1885을(를) 해결함")
2. **에픽 상세의 "하위 업무 항목" 패널** — 구조는 1과 동일 (진행률 `23 % 완료`, 같은 열 구성, "하위 항목 만들기")
   - 에픽은 제목 왼쪽에 **에픽 색상 사각형**, 세부 사항 카드에 **Epic Name** 필드
3. **브레드크럼의 부모 슬롯** — 하위 작업/에픽 소속 이슈를 열면 브레드크럼에 부모 키가 끼어든다 (없으면 "상위 항목 추가")
4. **백로그의 인라인 계층** — 부모 행에 **펼침 토글 + "하위 작업 N개" 버튼**, 펼치면 하위 작업이 **들여쓰기된 행**으로 바로 아래 나타난다 (타입 아이콘은 하위 작업 아이콘, 좌측 색 막대는 부모와 구분)
5. **에픽 소속 표시** — 백로그/보드 행·카드의 **좌측 세로 색 막대**가 소속 에픽 색. 목록 뷰에서는 그룹화(에픽 기준)로 표현
6. **연결된 이슈(issuelinks)는 계층이 아니다** — 상세의 별도 "연결된 업무 항목" 섹션에 관계 유형별(차단함/중복됨 등)로 나열된다

## 반응형: 1440px vs 1920px(전체화면) 비교

같은 화면을 1440×900과 1920×1080으로 캡처해 비교한 결과 (`jira-*-wide.png`):

- **좌측 사이드바는 고정 폭(~320px)** — 남는 폭은 전부 콘텐츠 영역이 가져간다. 넓어지면 사이드바 하단에 팀·사이드바 사용자 지정 항목까지 노출
- **상단 검색창**은 중앙 정렬로 뷰포트에 비례해 넓어진다
- **보드 탭 줄**: 좁으면 `More (N)` 드롭다운으로 접히고, 넓으면 인라인으로 풀린다 (1920에서는 개발·릴리스·보관된 업무 항목·문서·첨부 파일·바로 가기까지 노출)
- **목록(표)**: 열 폭은 고정이고 뷰포트가 넓어지면 보이는 열이 늘어난다 (1440: 보고자·우선 순위까지 + 가로 스크롤, 1920: 만듦까지 노출). 하단에 **고정 푸터**: `+ 만들기` / `129 중 50`(로드 건수) / 새로고침
- **이슈 상세**: **본문 가변 + 우측 사이드 패널 고정 폭(~300px)** 2단. 본문이 넓어지면 필드 그리드의 값 영역이 늘어난다. 하위 작업·첨부 섹션은 본문 폭 전체 사용
- **칸반 보드**: **컬럼이 화면 폭을 균등 분배**해 넓어진다 (PoC의 현재 구현과 동일한 동작). 카드가 넓어지면 키·경과시간·우선순위·아바타 메타가 한 줄로 합쳐진다
- **스윔레인**: 그룹(Highest 127, High 266 …)마다 컬럼 세트가 반복되고, 스윔레인별 컬럼 머리글에 건수가 따로 붙는다. 컬럼 하단에 `+`(해당 컬럼에 만들기)
- 추가 발견: 칸반 카드 안에 **상위 항목 선택 드롭다운 칩**이 노출되는 경우가 있다(부모를 카드에서 바로 바꾸는 UI). 오른쪽 아래에 Rovo 플로팅 버튼

## PoC 반영 우선순위 제안

1. 이슈 상세: 하위 작업 패널을 표+진행률 형태로 (현재는 단순 리스트) / 브레드크럼 부모 슬롯 (현재 구현과 유사, "상위 항목 추가" 유도 추가)
2. 백로그: 부모 행 펼침 + 하위 작업 들여쓰기, 스프린트 헤더에 상태 요약 칩 3개
3. 보드 카드: 좌측 에픽 색 막대, 라벨 칩, 하단 메타 줄(우선순위·아바타)
4. 목록(표): 그룹화(상태/담당자/에픽), 열 폭 조절
5. 전역 레이아웃(좌측 사이드바 + 프로젝트/보드 트리)은 React SPA 이전 시점에
