## 결정 사항 (2026-10-24)
1. **Jira 매크로**: Jira는 당분간 클라우드를 유지한다. Jira API로 이슈를 실시간 조회해 표시하고, 서버용 Jira 연동 토큰이 필요하다. Jira 자체 구현 여부는 Confluence 대체가 안정화된 뒤 검토한다.
   - 변환 시 이슈 키와 JQL을 데이터로 보존한다. Jira를 교체하더라도 렌더러만 바꾸면 되도록 한다.
2. **버전 이력**: 전체 251,171개 버전을 이관한다.
3. **배포와 첨부 저장소**: 사내 TrueNAS 서버에서 운영한다. 첨부는 기존 MinIO(S3 API)에 저장한다. 세부 사항은 `docs/architecture.md` 참고.
   - 첨부 이력(과거 버전) 포함 여부는 미정이다.
4. **개인 스페이스**: 135개 모두 이관한다.
5. **권한 모델**: Entra ID 그룹 중심으로 단순화한다. 이관 시 기존 사용자 단위 권한은 그대로 매핑해 보존한다.
