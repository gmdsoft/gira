# Confluence 설정 메뉴 분석

2026-10-24, 관리자 계정으로 전역 관리(`/wiki/admin`), 스페이스 설정(`/wiki/spaces/{key}/settings`), 개인 설정을 수집했다. 원본은 `analysis/raw/scenarios/set*-*.ax.txt`.
각 항목을 새 서비스 기준으로 분류한다: **MVP**(초기 구현) / 후순위 / **대체**(다른 수단으로 해결) / 제외.

## 전역 관리 (Confluence 관리)

### 최상위
| 메뉴 | 내용 | 새 서비스 |
|---|---|---|
| 미션 컨트롤 | 사이트 상태 대시보드 | **대체**: 운영 모니터링(Grafana 등) |
| 분석 | 조회수, 활성 사용자 통계 | 후순위 (`events` 테이블이 원천) |
| 감사 로그 | 관리 행위 기록 | 후순위. 단, 기록 자체는 MVP부터 `events`에 적재 |
| 자동화 | 규칙 기반 자동화(라벨 붙이면 보관 등) | 제외 (수요 확인 후) |
| 사용자 액세스 감사, 권한 데이터 내보내기 | 권한 감사 | 후순위 (SQL로 즉시 추출 가능) |
| 스페이스 | 전체 스페이스 목록, 일괄 관리 | **MVP** (관리자용 스페이스 목록: 보관, 삭제, 권한) |
| 공지 사항 | 사이트 배너 | 후순위 (구현 쉬움) |
| 다른 도구에서 가져오기 | 외부 가져오기 | **대체**: 우리 마이그레이션 도구가 이 역할 |
| 사용자 관리, 그룹 | admin.atlassian.com으로 이동 | **대체**: Entra ID가 원천. 앱에는 그룹→역할 매핑 화면만(MVP) |

### 환경설정
| 메뉴 | 내용 | 새 서비스 |
|---|---|---|
| 기본 구성 | 사이트 제목, 파비콘, 방문 페이지, **첨부 최대 크기(현재 100MB)·업로드당 개수(5)**, 연결 시간 제한 | **MVP**: `site_settings` 테이블 + 관리 화면 |
| 국제화 | 기본 언어, **색인 언어(한국어)** | **MVP**: ko 고정 + nori 색인. UI 다국어는 후순위 |
| 알림 | 이메일 알림 발신 설정 | **MVP**: SMTP 설정 |
| 새 기능, 바로가기 연결, 전역 양식과 블루프린트, PDF 내보내기 언어, 코드 매크로 설정 | 템플릿, 코드 하이라이트 테마 등 | 후순위 |

### 보안
| 메뉴 | 내용 | 새 서비스 |
|---|---|---|
| 보안 구성 | 세션, XSS 옵션 등 | **MVP에 내장**(설정이 아니라 기본 동작으로) |
| 공개 링크 | 외부 공개 공유 | 제외 권장. **사내 전용이므로 기본 차단**. 필요 여부 결정 필요 |
| 익명 액세스 | 비로그인 열람 | 제외 권장 (Entra 로그인 필수) |
| JSM 액세스, 팀 설정 | Atlassian 제품 연동 | 제외 |

### 권한
| 메뉴 | 내용 | 새 서비스 |
|---|---|---|
| 사이트 권한, 역할 | 전역 사용 권한, 역할 정의 | **MVP**: 사이트 관리자 그룹 지정 정도로 단순화 |
| 스페이스 기본값 | 새 스페이스의 기본 권한 템플릿 | **MVP** |
| 일괄 스페이스 액세스, 스페이스 역할, 스페이스 관리, 시스템 작업 | 일괄 권한 부여 | 후순위 |
| 액세스 요청, 게스트 액세스 | 외부인 초대 | 제외 (Entra 계정만) |

### 모양새
탐색 사용자 지정(로고, 색), 테마, PDF 내보내기 스타일, 머리글·바닥글, 기본 스페이스 로고, 워터마크
→ **MVP는 로고 교체와 라이트/다크 모드만**. 나머지 후순위.

### 데이터 관리
| 메뉴 | 내용 | 새 서비스 |
|---|---|---|
| 매크로 이용 | 매크로 사용 통계 | **대체**: 이미 인벤토리로 수행. 후순위로 내장 |
| Backup manager, 스페이스 가져오기 | 백업과 복원 | **대체**: pg_dump + MinIO 버전닝 + ZFS 스냅샷(운영 절차로 문서화) |
| 휴지통으로 이동한 스페이스 | 스페이스 휴지통 | **MVP**: 콘텐츠·스페이스 휴지통(`status=trashed`) |
| 스페이스 보고서, Jira 매크로 복구, 응용프로그램 연결, 어플리케이션 탐색기 | | 제외 |

### 애드온, 앱
설치된 서드파티: **HTML Macro Pro**, **Scroll PDF Exporter**, Scroll Exporter Extensions.
→ 플러그인 체계는 만들지 않는다. 변환기에서 이미 식별·보존 중이며(39건 등), **PDF 내보내기는 내장 기능**으로 대체한다(Scroll PDF Exporter가 유료로 하던 역할).

## 스페이스 설정
| 분류 | 메뉴 | 새 서비스 |
|---|---|---|
| (상단) | 자동화 | 제외 |
| 사용자 | 멤버·역할 관리 (현재 역할 체계 전환 안내 배너) | **MVP**: viewer/editor/admin 부여 화면 |
| 스페이스 세부 정보 | 이름, 키, 아이콘, 소유자, 관리자, 생성자 | **MVP** |
| 스페이스 액세스 | 익명 액세스 | 제외 |
| 콘텐츠 | **순서 변경**(트리 정렬), 숨김, **정의되지 않음**(생성 전 링크 목록), **첨부 파일**(스페이스 전체 첨부 목록), **보관됨** | MVP: 순서 변경(트리 드래그로 흡수), 보관함. 후순위: 첨부 일괄 목록, 미생성 링크 |
| 통합 | RSS 피드 | 후순위 |

## 개인 설정
개인 설정(언어, 시간대, 홈), 작업(내 할 일), 나중을 위해 저장(북마크), 지켜보기(watch 목록), 네트워크, 비밀번호·이메일, MS Teams, 편집자 설정, OAuth 접근 토큰
→ **MVP**: 프로필(Entra에서 동기화), 시간대, 지켜보기 목록, 알림 설정.
→ **대체**: 비밀번호·이메일은 Entra가 관리.
→ 후순위: 내 할 일 모아보기, 북마크. MS Teams 연동은 알림 웹훅으로 검토.

## 새로 확인된 수치
- 첨부 최대 크기 100 MB, 업로드당 5개 — 새 서비스 기본값도 동일하게 시작
- 색인 언어: 한국어 (nori 선택을 뒷받침)
- 서드파티 앱 3종이 전역 설치됨 (위 참조)
