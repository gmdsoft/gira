# 편집기 동작 명세 (Confluence 대비)

rea 캡처(`analysis/raw/scenarios/editor-*`)를 근거로 한 **기능 명세**다. Atlassian 코드/에셋은 사용하지 않고,
동작과 구성만 참고해 TipTap 위에 독자 구현한다. 근거 표기: `[캡처]` = rea 접근성 트리·스크린샷 실측,
`[문서]` = Atlassian 공개 문서의 단축키, `[미정]` = 추가 캡처 필요.

## 레이아웃 상수 [캡처]
- 본문 컬럼 760px, 편집·보기 동일. 넓은 표(>760px)는 컬럼 밖으로 중앙 돌출(breakout)
- 표 폭: `data-table-width` px. px 열 합이 그보다 크면 열 합이 실제 폭 (760은 기본값 표식으로 남는 경우 있음)

## 툴바 구성 [캡처: editor-open.ax.txt]
Confluence 상단 고정 툴바 순서:
1. (Rovo 글쓰기 — 범위 밖)
2. **텍스트 스타일 드롭다운** ("일반 텍스트" 표시, 제목 1~6·인용 선택)
3. **굵게** (Ctrl+B 표기), **형식 더 보기** (기울임·밑줄·취소선·코드·아래/위 첨자·서식 지우기)
4. **글머리 기호 목록**, **번호 목록**
5. **텍스트 정렬** (왼쪽/가운데/오른쪽)
6. **텍스트 색상**
7. **작업 항목**, **이미지·동영상·파일**, **멘션**, **이모지**, **레이아웃**, (탭·동기화 블록 — 범위 밖)
8. **표**, **표 크기**(그리드 선택기), **요소 삽입(+)** (전체 요소 카탈로그)
9. **링크**
10. **실행 취소 / 다시 실행 / 변경 사항 보기**

우리 구현 대응: 2·3·4·9·실행취소는 있음. 추가할 것 → 텍스트 스타일 드롭다운, 텍스트 정렬,
텍스트 색상 팔레트, 멘션(@), 표 그리드 선택기, 레이아웃(2단/3단).

## 슬래시(/) 메뉴 [캡처: editor-slash_menu.png]
첫 화면(사용 빈도순): 링크(Ctrl+K 표기), 다이어그램, 데이터베이스, 작업 항목(`[]` 표기),
이미지·동영상·파일, 멘션(`@` 표기), 동기화된 블록, 이모지, Jira 업무 항목, 펼치기, "모든 요소 보기".
- 각 항목: 아이콘 + 제목 + 한 줄 설명 + 단축 트리거 배지
- 하단 "더 보기"로 전체 카탈로그 [미정: 전체 목록 캡처 필요]

우리 구현 대응: 16종 보유. 보강 → 항목에 설명·트리거 배지 표기, 멘션/날짜/상태/인용/레이아웃 추가.

## 단축키 [캡처: editor-help-dialog.ax.txt — Ctrl+/ 도움말 전문]
Confluence 편집기 도움말 대화상자(Ctrl+/)에서 뜬 전체 목록. ✓=우리 구현 완료, +=추가 대상, —=범위 밖.

| 취소선 | Ctrl+Shift+S | ✓ |
| 밑첨자 / 위첨자 | Ctrl+Shift+, / Ctrl+Shift+. | + |
| 코드 | Ctrl+Shift+M | ✓ |
| 서식 지우기 | Ctrl+\ | ✓ |
| 일반 텍스트 | Ctrl+Alt+0 | ✓ |

| 글머리 / 번호 목록 | Ctrl+Shift+8 / 7 | ✓ |

| 구분선 | Ctrl+Shift+- | + |

## 입력 자동 서식 (마크다운) [캡처: 도움말 Markdown 섹션]
`#`~`######`+공백 제목, `*`/`1.`+공백 목록, `>`+공백 인용, ``` ``` `` 코드블록, `---` 구분선,
`**굵게**`, `*기울임*`, `~~취소선~~`, `` `코드` ``, `[링크](url)` — TipTap StarterKit 기본으로 동일 ✓
- Confluence 추가분: `[]`+공백 → 작업 항목 ✓(구현), `<>`+공백 → 결정(decision) + (후속)

## 트리거 문자 [캡처: 카탈로그/도움말]
- `/` 빠른 삽입 ✓
- `@` 멘션 ✓ (/api/principals)
- `:` 이모지 ✓ (유니코드 목록. Atlassian 커스텀 이모지는 범위 밖)
- `//` 날짜 삽입 + (후속)

## 요소 삽입 전체 카탈로그 [캡처: editor-insert-catalog.ax.txt]
링크, 다이어그램—, 데이터베이스—, 작업 항목 ✓, 이미지·파일 ✓, 멘션 ✓, 동기화 블록—, 이모지 ✓,
Jira 업무 항목—, 펼치기 ✓, 표 ✓, 코드 조각 ✓, 상태 ✓, 날짜 ✓, 결정+,
패널: 정보 ✓ / 노트 ✓ / 성공 ✓ / 경고 ✓ / 오류 ✓ / 사용자 지정+,
레이아웃: 1·2·3·4·5열 (우리: 2·3열 ✓, 1·4·5 후속), 머릿글 1~3, 글머리·번호 목록, 구분선, 인용.

## 블록 편집 (비텍스트 요소: 표·패널·펼치기·코드블록·레이아웃 등)
- **선택/삭제/복사·붙여넣기** ✓: 블록에 마우스를 올리면 왼쪽에 핸들(⣿)이 뜨고, 누르면 블록
  전체가 선택(NodeSelection)된다 → Delete 삭제, Ctrl+C/V 복사·붙여넣기 (`BlockHandle`).
  중첩(펼치기 안 패널 등)은 포인터 아래 가장 안쪽 블록을 겨냥하고, 핸들로 이동 중엔 사라지지 않는다.
- **컨테이너 안 Enter** ✓: 패널·펼치기 등 안에서 Enter는 블록을 넓힌다(내부에 줄 추가) — Confluence 동일.
- **컨테이너 탈출** ✓: 블록 안 마지막 줄에서 ↓(아래 화살표)로 블록 밖으로 나간다 (gapcursor + 후행 문단).
- **블록 아래 Backspace** ✓: 블록 바로 아래 문단 맨 앞에서 Backspace — 빈 문단이면 앞 블록 삭제,
  내용이 있으면 앞 블록 선택(합치지 않음) (`BlockBackspace`).
- **후행 문단** ✓: 문서가 블록으로 끝나면 그 아래 빈 문단을 자동 유지해 커서를 내릴 수 있다 (`TrailingNode`).
- **크기 변경(resize)** — (후속): 표/이미지 리사이즈 핸들. 범위가 커 별도 작업.
- **드래그 이동** — (후속): 핸들 드래그로 블록 순서 변경.

## 범위 밖 (PoC에서 구현하지 않음)
Rovo(AI), 다이어그램·데이터베이스·동기화 블록·탭·Jira 업무 항목 삽입, 듣기(TTS), 반응, Loom,
리믹스, 실시간 presence(Yjs 도입 때), 변경 사항 보기(버전 diff로 대체), 작은 텍스트.
