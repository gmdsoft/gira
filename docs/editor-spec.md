# 편집기 동작 명세 (Confluence 대비)

rea 캡처(`analysis/raw/scenarios/editor-*`)를 근거로 한 **기능 명세**다. Atlassian 코드/에셋은 사용하지 않고,
동작과 구성만 참고해 TipTap 위에 독자 구현한다. 근거 표기: `[캡처]` = rea 접근성 트리·스크린샷 실측,
`[문서]` = Atlassian 공개 문서의 단축키, `[미정]` = 추가 캡처 필요.

## 레이아웃 상수 [캡처]
- 본문 컬럼 760px, 편집·보기 동일. 넓은 표(>760px)는 컬럼 밖으로 중앙 돌출(breakout)
- 표 폭: `data-table-width` px. px 열 합이 그보다 크면 열 합이 실제 폭 (760은 기본값 표식으로 남는 경우 있음)

## 툴바 구성 [캡처: editor-open.ax.txt]
Confluence 상단 고정 툴바 순서:
1. (Rovo 글쓰기 — 범위 밖)
2. **텍스트 스타일 드롭다운** ("일반 텍스트" 표시, 제목 1~6·인용 선택)
3. **굵게** (Ctrl+B 표기), **형식 더 보기** (기울임·밑줄·취소선·코드·아래/위 첨자·서식 지우기)
4. **글머리 기호 목록**, **번호 목록**
5. **텍스트 정렬** (왼쪽/가운데/오른쪽)
6. **텍스트 색상**
7. **작업 항목**, **이미지·동영상·파일**, **멘션**, **이모지**, **레이아웃**, (탭·동기화 블록 — 범위 밖)
8. **표**, **표 크기**(그리드 선택기), **요소 삽입(+)** (전체 요소 카탈로그)
9. **링크**
10. **실행 취소 / 다시 실행 / 변경 사항 보기**

우리 구현 대응: 2·3·4·9·실행취소는 있음. 추가할 것 → 텍스트 스타일 드롭다운, 텍스트 정렬,
텍스트 색상 팔레트, 멘션(@), 표 그리드 선택기, 레이아웃(2단/3단).

## 슬래시(/) 메뉴 [캡처: editor-slash_menu.png]
첫 화면(사용 빈도순): 링크(Ctrl+K 표기), 다이어그램, 데이터베이스, 작업 항목(`[]` 표기),
이미지·동영상·파일, 멘션(`@` 표기), 동기화된 블록, 이모지, Jira 업무 항목, 펼치기, "모든 요소 보기".
- 각 항목: 아이콘 + 제목 + 한 줄 설명 + 단축 트리거 배지
- 하단 "더 보기"로 전체 카탈로그 [미정: 전체 목록 캡처 필요]

우리 구현 대응: 16종 보유. 보강 → 항목에 설명·트리거 배지 표기, 멘션/날짜/상태/인용/레이아웃 추가.

## 단축키
표기 근거: 툴바 레이블의 Ctrl+B [캡처], 슬래시 메뉴의 Ctrl+K·`[]`·`@` [캡처], 나머지는 Atlassian 공개
단축키 문서 [문서] — Ctrl+/ 도움말 대화상자 캡처로 확정 예정 [미정].

| 동작 | 단축키 | 상태 |
|---|---|---|
| 굵게 / 기울임 / 밑줄 | Ctrl+B / I / U | TipTap 기본 ✓ |
| 취소선 | Ctrl+Shift+S | TipTap 기본 ✓ |
| 인라인 코드 | Ctrl+Shift+M (+ TipTap Ctrl+E) | 추가 |
| 서식 지우기 | Ctrl+\ | 추가 |
| 일반 텍스트 / 제목 1~6 | Ctrl+Alt+0 / 1~6 | 0 추가 (1~6 TipTap 기본 ✓) |
| 글머리 / 번호 목록 | Ctrl+Shift+8 / 7 | TipTap 기본 ✓ |
| 인용 | Ctrl+Shift+9 | 추가 (TipTap Ctrl+Shift+B 유지) |
| 링크 | Ctrl+K | 추가 |
| 게시(업데이트) | Ctrl+Enter, Ctrl+S | 구현됨 ✓ |
| 실행 취소 / 다시 실행 | Ctrl+Z / Ctrl+Y | TipTap 기본 ✓ |

## 입력 자동 서식 (마크다운 입력 규칙)
TipTap StarterKit 기본 제공으로 Confluence와 동일 동작: `#`+공백 제목, `*`/`-` 글머리,
`1.` 번호, `>` 인용, ``` 코드 블록, `---` 구분선. [문서]
- Confluence 추가분: `[]`+공백 → 작업 항목 [캡처: 슬래시 배지] → 입력 규칙 추가

## 트리거 문자
- `/` 요소 메뉴 ✓ 구현됨
- `@` 멘션 — 사용자 검색 팝업, 선택 시 mention 노드 [캡처] → `/api/principals`로 구현
- `:` 이모지 검색 [캡처: 툴바] → 유니코드 상용 이모지 목록으로 구현 (Atlassian 커스텀 이모지는 범위 밖)

## 범위 밖 (PoC에서 구현하지 않음)
Rovo(AI), 다이어그램(drawio 보기 전용 유지), 데이터베이스, 동기화 블록, 탭, Jira 업무 항목 삽입,
듣기(TTS), 반응, Loom, 리믹스, 실시간 presence(Yjs 도입 때), 변경 사항 보기(버전 diff로 대체).
